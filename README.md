# lightway-backend

Backend de LightWay Cameroon : gateway GraphQL (NestJS), services Spring Boot, contrats, infrastructure.

## Structure
- `gateway/` : gateway NestJS GraphQL
- `services/` : microservices (auth-service, utilisateurs-service, ...)
- `contracts/` : schémas d'événements et schéma GraphQL
- `infra/` : Docker Compose, bases, bus, proxy, scripts
- `docs/` : conception, décisions (ADR), collections d'API
